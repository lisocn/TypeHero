## M01 项目基础架构（P0）

### 1.1 功能概述
搭建前端工程脚手架，确定技术栈、目录结构、路由体系、状态管理和全局设计规范。

### 1.2 技术选型

| 类别    | 选型                                  | 说明            |
| ----- | ----------------------------------- | ------------- |
| 前端框架  | React 18 + TypeScript               | 组件化开发         |
| 构建工具  | Vite                                | 快速热更新         |
| 状态管理  | Zustand                             | 轻量级，适合中小型项目   |
| 路由    | React Router v6                     | 页面路由          |
| 样式方案  | Tailwind CSS + CSS Modules          | 原子化 + 局部样式隔离  |
| 动画    | Framer Motion + Lottie              | 页面过渡 + 角色动画   |
| 数据持久化 | localStorage（MVP） + Supabase（后续云同步） | 离线优先          |
| 字体    | 思源黑体 + Google Fonts（Nunito 等可爱风）    | 需通过 link 标签加载 |

## M02 用户系统（P0）

### 2.1 功能概述
实现本地用户注册、角色创建、个人信息管理。MVP 阶段使用 localStorage 存储，无需后端。

### 2.2 数据模型

User {
  id: string              # UUID，自动生成
  nickname: string        # 昵称，2-12个字符
  avatar: string          # 角色形象ID
  level: number           # 当前等级，初始1
  exp: number             # 当前经验值
  totalExp: number        # 总经验值
  coin: number            # 金币数，初始0
  createdAt: string       # 创建时间 ISO
  settings: {
    soundEnabled: boolean  # 音效开关
    musicEnabled: boolean  # 背景音乐开关
    difficulty: 'auto' | 'easy' | 'medium' | 'hard'
  }
}

Avatar 角色形象选项（初始4个，可解锁更多）：
  - astronaut（宇航员）
  - ninja（忍者）
  - princess（公主）
  - knight（龙骑士）

等级经验表：
  Level 1: 0 exp
  Level 2: 100 exp
  Level 3: 250 exp
  Level N: 100 * N * 1.2 (向上取整)

经验值获取：
  - 通关1关: +30 exp
  - 金星通关: +50 exp（额外）
  - 每日打卡: +20 exp
  - 连击奖励: +2 exp/连击

### 2.3 页面与交互

#### 2.3.1 首页（/）
- 大标题 "TypeHero 打字小英雄"
- 副标题 "成为键盘英雄，征服文字世界！"
- 主按钮 "开始冒险" -> 跳转登录/直接进入（已登录状态）
- 背景动画：漂浮的字母和汉字粒子

#### 2.3.2 注册登录（/login）
- MVP阶段为本地创建用户，无需密码
- 输入昵称（2-12字符，不允许特殊字符）
- 选择角色形象（4选1，点击头像高亮，带预览动画）
- 点击"创建英雄"按钮
- 创建成功后自动跳转至闯关地图

#### 2.3.3 个人主页（/profile）
- 顶部：角色形象展示（大图）+ 昵称 + 等级进度条
- 中部统计卡片（4个）：
  - 总打字量（字符数）
  - 最高WPM
  - 获得奖章数
  - 连续打卡天数
- 下方 Tab 切换：
  - 成长曲线图（近7天/30天的WPM和准确率折线图）
  - 我的称号列表
  - 设置面板（音效/难度/重置数据）

### 2.4 验收标准

- [ ] 首次访问显示注册页面，昵称输入有字数和格式校验
- [ ] 角色选择可点击切换，选中状态有明显视觉反馈
- [ ] 注册成功后 localStorage 中存在 user 数据
- [ ] 已注册用户访问首页自动跳转闯关地图
- [ ] 个人主页统计数据与实际游戏数据一致
- [ ] 等级经验值计算正确，升级时有动画提示
- [ ] 设置面板中开关可正常切换，设置项持久化

## M03 打字引擎（P0 — 核心模块）

### 3.1 功能概述
打字引擎是整个项目的底层核心。负责实时捕获键盘输入、计算 WPM/准确率/连击、管理打字状态，
并对外提供统一的 Hook 接口供各游戏模式调用。

### 3.2 核心接口设计

useTypingEngine(config: TypingEngineConfig) => TypingEngineState

TypingEngineConfig {
  mode: 'char' | 'word' | 'sentence'  # 打字粒度
  content: string[]                     # 目标内容数组
  timeLimit: number                     # 时间限制（秒），0=不限时
  difficulty: 'easy' | 'medium' | 'hard'  # 难度
  onComplete: (result: TypingResult) => void  # 完成回调
  onTick: (remaining: number) => void         # 每秒回调
}

TypingEngineState {
  status: 'idle' | 'playing' | 'paused' | 'finished'
  currentIndex: number          # 当前字符/词/句索引
  currentChar: string           # 当前需要输入的字符
  typedChars: TypedChar[]       # 已输入字符记录
  wpm: number                   # 当前 WPM
  accuracy: number              # 当前准确率（0-100）
  combo: number                 # 当前连击数
  maxCombo: number              # 最大连击数
  remainingTime: number         # 剩余秒数
  progress: number              # 进度百分比（0-100）
  start: () => void             # 开始
  pause: () => void             # 暂停
  resume: () => void            # 恢复
  reset: () => void             # 重置
}

TypedChar {
  expected: string              # 期望字符
  typed: string                 # 实际输入
  correct: boolean              # 是否正确
  timestamp: number             # 输入时间戳
}

TypingResult {
  totalChars: number            # 总字符数
  correctChars: number          # 正确字符数
  wrongChars: number            # 错误字符数
  accuracy: number              # 最终准确率
  wpm: number                   # 最终 WPM
  maxCombo: number              # 最大连击
  duration: number              # 实际用时（秒）
  stars: 1 | 2 | 3              # 获得星数
  exp: number                   # 获得经验值
  coin: number                  # 获得金币
}

### 3.3 WPM 计算公式

WPM = (正确输入的字符数 / 5) / (实际用时分钟数)
说明：5个字符 = 1个标准单词

### 3.4 准确率计算

accuracy = (正确字符数 / 总输入字符数) * 100
注意：退格删除的字符也计入总输入次数

### 3.5 星级评定规则

| 星级 | 条件 |
|------|------|
| 1星（铜） | 完成打字，准确率 >= 70% |
| 2星（银） | 准确率 >= 90% 且 WPM >= 当关基准线 |
| 3星（金） | 准确率 >= 97% 且 WPM >= 当关基准线*1.4 |

### 3.6 连击（Combo）机制

- 连续输入正确：combo + 1
- 输入错误：combo 归零，播放"断裂"音效
- combo >= 10：显示 "Nice!" 特效
- combo >= 30：显示 "Amazing!" 特效
- combo >= 50：显示 "Legendary!" 全屏特效
- combo 触发的经验值奖励：每连击 +2 exp（在结算时一次性发放）

### 3.7 键盘可视化组件

功能：在打字区域下方显示虚拟键盘，实时高亮下一个需要按的键。

虚拟键盘布局：
  第1行：` 1 2 3 4 5 6 7 8 9 0 - =
  第2行：Q W E R T Y U I O P [ ] \
  第3行：A S D F G H J K L ; '
  第4行：Z X C V B N M , . /
  第5行：Space（空格键，宽键）

视觉效果：
  - 默认状态：深灰色按键
  - 当前目标键：金色高亮 + 轻微脉冲动画
  - 正确按下：绿色闪烁 0.2s
  - 错误按下：红色闪烁 + 抖动 0.3s
  - 手指引导：可选功能，显示哪个手指应该按（颜色标注10个手指区域）

### 3.8 音效系统

| 事件 | 音效 | 说明 |
|------|------|------|
| 按键正确 | 清脆 click | 轻微，不扰人 |
| 按键错误 | 低沉 buzz | 明显但不刺耳 |
| 连击 10 | 升调叮 | 激励感 |
| 连击 30 | 鼓点 | 激动 |
| 连击 50 | 史诗音效 | 震撼 |
| 关卡完成 | 胜利号角 | 成就感 |
| 升级 | 升级号角 | 庆祝 |
| 获得奖章 | 宝箱开启 | 稀有感 |

音效实现：
  - 使用 Web Audio API
  - 预加载所有音效文件到内存
  - 支持音效开关（读取用户设置）
  - 音效音量独立于系统音量

### 3.9 错误处理

| 场景 | 处理方式 |
|------|----------|
| 用户按下 Shift/Ctrl/Alt 等修饰键 | 忽略，不计入统计 |
| 用户按下 Esc | 暂停游戏，弹出暂停菜单 |
| 用户按下退格键 | 允许删除上一个字符，该字符标记为已修正 |
| 浏览器失焦（切换标签页） | 自动暂停，回来后提示继续 |
| 非英文字符输入法激活 | 显示提示"请切换到英文输入法" |

### 3.10 验收标准

- [ ] 输入正确字符时，currentIndex 前进，combo +1
- [ ] 输入错误字符时，错误字符标红，combo 归零
- [ ] WPM 计算实时更新，数值与手动计算一致（误差 < 1）
- [ ] 准确率实时更新，数值正确
- [ ] 时间到自动结束，触发 onComplete 回调
- [ ] 连击特效在对应阈值正确触发
- [ ] 虚拟键盘正确高亮目标按键
- [ ] 音效在对应事件触发，开关可控制
- [ ] Esc 暂停正常，浏览器失焦自动暂停
- [ ] 退格键可正常删除上一个字符
- [ ] 修饰键（Shift/Ctrl/Alt）被正确忽略
- [ ] 打字过程中无明显卡顿，60fps 流畅

## M04 关卡系统（P0）

### 4.1 功能概述
基于教材内容的闯关系统。包含关卡数据管理、闯关地图展示、关卡内游戏流程、评分结算。

### 4.2 数据模型

Chapter（章节） {
  id: string                  # 如 "eng-3a-u1"
  title: string               # 如 "字母王国"
  subtitle: string            # 如 "三年级上 Unit 1"
  subject: 'english' | 'chinese'
  order: number               # 排序序号
  icon: string                # 章节图标
  bgTheme: string             # 背景主题ID
  levels: Level[]             # 该章节下所有关卡
  bossLevel: Level            # BOSS关
  unlockCondition: string     # 解锁条件描述
}

Level（关卡） {
  id: string                  # 如 "eng-3a-u1-l1"
  title: string               # 如 "热身：字母击落"
  type: 'warmup' | 'basic' | 'advanced' | 'boss'
  order: number
  content: LevelContent       # 打字内容
  targetWPM: { bronze: 15, silver: 25, gold: 35 }
  targetAccuracy: { bronze: 80, silver: 90, gold: 97 }
  timeLimit: number           # 秒，0=不限时
  unlockCondition: { previousLevelId: string }
  reward: { exp: number, coin: number }
}

LevelContent {
  mode: 'char' | 'word' | 'sentence' | 'paragraph'
  items: ContentItem[]
  language: 'en' | 'zh-pinyin' | 'zh-hanzi'
}

ContentItem {
  display: string             # 屏幕显示的内容
  input: string               # 要求输入的内容
  hint?: string               # 提示信息
}

### 4.5 关卡内游戏流程

  loading -> countdown -> playing -> paused -> result -> next

详细流程：
  1. loading：加载关卡数据，预加载音效，显示关卡名
  2. countdown：3-2-1 倒计时动画
  3. playing：正式游戏，调用打字引擎
     - 屏幕顶部：进度条 + 剩余时间 + 连击数
     - 屏幕中央：当前需要输入的内容（大字显示）
     - 屏幕中下：已输入内容区域（正确=绿色，错误=红色下划线）
     - 屏幕底部：虚拟键盘
  4. paused：暂停菜单（继续/重新开始/退出）
  5. result：结算面板
     - 动画展示：星级评定（从低到高依次亮起）
     - 数据展示：WPM / 准确率 / 用时 / 最大连击
     - 奖励展示：经验值 + 金币 + 是否获得新奖章
     - 按钮：下一关 / 重玩 / 返回地图

### 4.6 难度自适应系统

规则引擎（在 useTypingEngine 内部实现）：

  输入条件：
    recentAccuracy: 最近5次的准确率均值
    recentWPM: 最近5次的WPM均值
    currentCombo: 当前连击表现

  调整策略：
    if recentAccuracy > 95% && recentWPM > targetWPM * 1.2
      -> 提示"你已经很厉害了，试试更高难度！"
      -> 下一关自动将 targetWPM 提升 10%

    if recentAccuracy < 70%
      -> 显示"加油！我们降低一点难度"
      -> 下一关 targetWPM 降低 15%
      -> 弹出鼓励语 + 针对性练习建议

    if 某字母/key 错误率 > 30%
      -> 在后续关卡中增加该字母出现频率 20%
      -> 在虚拟键盘上用特殊颜色标注该键

### 5.2 疾风打字模式（/speed）

规则：
  - 固定60秒计时
  - 随机从已解锁教材内容池中抽取单词/句子
  - 输入一个自动跳下一个
  - 结束后统计：总输入字符数、正确数、WPM、准确率、最大连击

UI布局：
  - 顶部：60秒倒计时（圆形进度条）+ 当前WPM实时显示
  - 中央：当前单词/句子（大字体，居中）
  - 下方：最近5个已输入词的反馈（正确=绿色删除线，错误=红色）
  - 底部：虚拟键盘

结算面板：
  - 动画数字滚动展示成绩
  - 与个人历史最佳对比（"新纪录！" 或 "距离最佳还差 X WPM"）
  - 获得金币和经验值
  - 按钮：再来一局 / 返回

### 5.3 BOSS挑战模式

规则：
  - 每章通关后解锁该章BOSS关
  - BOSS关混合本章所有内容类型
  - 有生命值系统：初始3条命，输入错误扣1命
  - 有时间限制：根据内容量动态计算
  - 通关条件：在生命值归零前完成所有内容
  - 特殊奖励：击败BOSS获得该章限定称号

BOSS展示：
  - 进入BOSS关前有BOSS出场动画
  - BOSS有血量条（正确输入扣BOSS血量）
  - 玩家有血量条（错误输入扣玩家血量）
  - BOSS剩余10%血量时进入"狂暴模式"：内容速度加快

### 5.4 趣味小游戏

#### 5.4.1 字母雨（Letter Rain）
  场景：全屏下落游戏
  规则：
    - 字母/汉字从屏幕顶部随机位置下落

    - 漏掉一个扣1命，共5条命

    - 特殊金色字母：击碎获得双倍金币
  难度选项：
    - 简单：只有大写字母
    - 中等：大小写混合
    - 困难：单词片段
  适用教材：英语字母表 / 语文拼音声母韵母

#### 5.4.2 成语接龙打字（Idiom Chain）

  规则：
    - 系统给出一个成语，如"一心一意"

  成语库：

  诗句库：
    - 来自部编版小学语文课本古诗词 + 常见拓展古诗
    - 初始200句

#### 5.4.4 单词消消乐（Word Match）
  场景：网格布局
  规则：
    - 屏幕显示4x4网格，每格一个英语单词
    - 系统提示目标单词（如 "ruler"）
    - 孩子输入该单词，正确后该格消除（爆炸动画）
    - 全部消除即过关
    - 有计时，越快星星越多

#### 5.4.5 课文修复师（Text Repair）
  场景：课文页面
  规则：
    - 屏幕显示一段课文，其中部分汉字/单词被"损坏"（显示为方块 □）
    - 孩子需要在损坏位置输入正确内容
    - 完成后课文恢复完整，有"修复完成"动画
    - 准确率和速度决定星级

### 7.4 奖章触发检测机制

检测时机：
  - 每次关卡结算完成后
  - 每次打卡完成后
  - 每次疾风打字/小游戏结算后

检测流程：
  1. 遍历所有未解锁的 Achievement
  2. 根据 condition.type 读取对应用户数据
  3. 判断是否满足 params 条件
  4. 满足 -> 解锁奖章 -> 记录 UserAchievement -> 标记 notified=false
  5. 检测完成后，检查是否有 notified=false 的奖章
  6. 有 -> 弹出奖章获得通知

### 7.5 奖章获得通知

弹窗内容：
  - 金色光芒特效背景
  - 奖章图标（大尺寸，带旋转动画）
  - "恭喜获得新奖章！"
  - 奖章名称 + 描述
  - 奖励明细（金币 + 经验 + 称号）
  - "太棒了！" 按钮关闭

多个奖章同时获得时：
  - 依次展示，每张间隔 1 秒
  - 或合并为"今日收获"面板

### 7.6 奖章殿堂页面（/achievements）

布局：
  - 顶部：统计区（已获得 X/总数，铜 X/银 X/金 X/传说 X）
  - 分类 Tab：全部 / 速度 / 准确率 / 坚持 / 教材 / 隐藏
  - 奖章网格：4列卡片
    - 已解锁：彩色图标 + 名称 + 解锁日期
    - 未解锁（非隐藏）：灰色图标 + 名称 + 获取条件
    - 未解锁（隐藏）：问号图标 + "???" + "继续探索解锁更多秘密"
  - 点击已解锁奖章 -> 弹出详情（大图标 + 描述 + 解锁时间 + 奖励）
  - 点击未解锁 -> 弹出提示（如何获得该奖章）
