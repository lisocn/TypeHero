
# TypeHero 打字小英雄 - 项目规划方案

这个方案的核心逻辑是：**孩子以为自己在玩游戏，实际每分钟都在练习键盘和复习课本内容。** 打字是手段，教材复习是载体，游戏化是驱动力——三者融为一体。

## 一、Project Name 推荐

| 项目名 | 定位 | 风格 |
|--------|------|------|
| TypeHero 打字小英雄 (推荐) | 主打英雄闯关叙事，孩子每打对一段文字就是一次英雄壮举 | 热血冒险 |
| KeyNinja 键盘忍者 | 忍者修炼隐喻，手指越快忍术越强 | 日式酷炫 |
| TypeCraft 打字工坊 | 类 Minecraft 像素风，打字=采集资源=建造世界 | 沙盒创造 |
| 打字冒险岛 | 冒险岛风格，地图探索式学习 | 童趣探索 |

推荐 TypeHero 打字小英雄 - 名字自带正向激励感，孩子天然渴望成为英雄，品牌记忆点强，便于后期延展故事线。

## 二、趣味性 x 教材融合设计

### 核心理念：打字就是闯关的武器，教材内容就是关卡的剧情

孩子不是在练习打字，而是在用打字技能完成冒险任务——输入的内容恰好来自课本。

### 2.1 教材内容映射体系

北京市小学教材内容池：

英语（人教PEP）：
- 单元核心词汇
- 重点句型对话
- Let's talk 片段
- Story time 故事
- 自然拼读组合

语文（部编版）：
- 生字 + 拼音
- 古诗词默写
- 课文经典段落
- 成语接龙
- 好词好句摘抄

#### 英语关卡示例（以三年级上册 Unit 1 为例）

关卡名称：字母王国 第一关

战斗任务：守护字母王国，击退入侵的拼写怪兽

- 热身层：逐字母击落，屏幕飘落随机字母气球，孩子按下对应键击碎
- 基础层：单词狩猎，怪兽身上显示 ruler / pencil / eraser，正确输入单词击败怪兽
- 进阶层：句子结界，出现魔法屏障，需要完整输入 "I have a ruler. Me too!"，输入完成后屏障碎裂，获得宝箱
- BOSS层：对话对决，系统扮演角色A，孩子扮演角色B，输入对应对话完成挑战

#### 语文关卡示例（以三年级上册望天门山为例）

关卡名称：诗意江湖 长江篇

剧情：诗人李白被困在湍急的天门山江面，需要你输入诗句来架桥逃生

- 第一桥（拼音输入层）：屏幕显示拼音，孩子输入拼音，诗句浮出水面
- 第二桥（汉字输入层）：显示完整诗句逐字浮现，逐字打出
- 第三桥（整诗默写层）：只显示题目，默写全诗四句
- 隐藏奖励：输入诗人生平小知识获得额外星星

### 2.2 五种趣味练习模式

| 模式 | 说明 | 适合场景 |
|------|------|----------|
| 疾风打字 | 计时模式：60秒内输入尽可能多的单词/诗句 | 快速练习、课间碎片时间 |
| 英雄闯关 | 关卡推进模式：按教材单元顺序解锁 | 系统学习、假期每日任务 |
| BOSS挑战 | 每章结束后的大关：混合本单元所有内容，限时+准确率双要求 | 击败BOSS获稀有奖章 |
| 趣味小游戏 | 衍生玩法（详见下方） | 调节气氛、增加新鲜感 |
| 双人对战 | 同屏PK：相同内容谁打得又快又准 | 亲子互动、同学间比拼 |

#### 趣味小游戏详解

| 游戏名 | 玩法 | 融合内容 |
|--------|------|----------|
| 字母雨 | 字母/汉字从天而落，输入正确按键击碎，漏掉扣命 | 26个字母/拼音声母韵母 |
| 成语接龙打字 | 系统出成语末字，孩子输入下一个成语 | 语文成语积累 |
| 诗词飞花令 | 给定主题字，输入含该字的古诗句 | 古诗词拓展 |
| 单词消消乐 | 相同单词在屏幕聚拢，快速输入消除 | 英语词汇巩固 |
| 课文修复师 | 课文段落中有缺字空格，输入正确内容修复 | 课文原文重现 |

### 2.3 趣味视觉与交互

英雄角色系统：
- 孩子创建自己的打字英雄
- 选择角色形象（宇航员/忍者/公主/龙骑士）
- 角色随等级提升而进化外观
- 每输入一个正确字符，英雄发动攻击动画
- 连击（combo）触发炫酷特效
- 打错时英雄受伤，鼓励重新来过

环境主题随教材单元切换：
- Unit 1 -> 学校场景
- Unit 2 -> 森林场景
- Unit 3 -> 海洋场景
- 古诗单元 -> 水墨山水
## 三、闯关 / 打卡 / 奖章 系统设计

### 3.1 闯关体系（核心成长线）

世界观地图：

| 章节 | 名称 | 对应内容 | 定位 |
|------|------|----------|------|
| 第1章 | 校园觉醒 | 三年级上 Unit1-3 | 新手村 |
| 第2章 | 森林试炼 | 三年级上 Unit4-6 | 进阶区 |
| 第3章 | 暑假特别篇 | 古诗词大冒险 | 假期限定 |
| 第4章 | 山巅挑战 | 三年级下 Unit1-3 | 挑战区 |
| 第5章 | 深海秘境 | 三年级下 Unit4-6 | 高阶区 |
| 终章 | 英雄殿堂 | 综合大考验 | 终极BOSS |

#### 每章内部结构

每章 = 6个小关 + 1个BOSS关

每个小关内部三层难度：

| 难度 | 速度要求 | 准确率要求 | 说明 |
|------|----------|------------|------|
| 铜星通关 | >= 15 WPM | >= 80% | 完成即过关 |
| 银星通关 | >= 25 WPM | >= 90% | 有时间限制 |
| 金星通关 | >= 35 WPM | >= 97% | 极限挑战 |

集齐一章所有金星 -> 解锁隐藏皮肤/称号

#### 难度自适应算法

- 连续5次准确率 > 95% -> 自动提升一档速度要求
- 连续3次准确率 < 70% -> 温和降低难度 + 弹出鼓励语
- 某字母频繁出错 -> 后续关卡增加该字母出现频率

目标：保证孩子始终处于"努努力刚好够得着"的心流区间。
### 3.2 每日打卡系统

暑假打卡日历示意：
- 显示当月日历，已打卡日期标记绿色勾
- 显示：连续打卡天数、本月累计天数、总练习时长、今日目标完成度

#### 打卡机制细节

| 机制 | 设计 |
|------|------|
| 每日目标 | 每天完成 2个关卡 + 10分钟自由练习 即算打卡成功 |
| 打卡奖励 | 每日签到获得金币（连续天数越多，金币翻倍） |
| 补签卡 | 每月赠送2张补签卡，断签不绝望 |
| 连续激励 | 连续7天=银色周冠 / 连续21天=金色月冠 / 连续30天=传奇全勤王 |
| 时段加成 | 早9-11点练习 = 1.5倍金币（引导规律作息） |
| 家长可见 | 每日自动生成练习报告推送给家长（可选微信推送） |

#### 金币经济系统

金币获取：
- 每日打卡 +10~30
- 关卡通关 +20~80
- 金星通关 +50额外
- 连击奖励 +5/连击
- 成就达成 +100~1000

金币消耗：
- 解锁角色皮肤 100~500
- 解锁键盘特效 200~800
- 解锁宠物伙伴 300~1000
- 解锁称号边框 150~600
- 装饰个人主页 100~400

目标：让孩子为了获得想要的奖励而主动多练。
### 3.3 奖章（成就）体系

#### 奖章等级分类

- 铜章（入门级）：30+ 种
- 银章（进阶级）：20+ 种
- 金章（大师级）：10+ 种
- 传说奖章：仅 3 枚（暑期终极目标）

#### 奖章详细设计

**一、速度类奖章**

| 奖章 | 铜章 | 银章 | 金章 |
|------|------|------|------|
| 手速之王 | 20 WPM | 35 WPM | 50 WPM |
| 极速闪电 | 30秒内完成1关 | 20秒内完成1关 | 15秒内完成1关 |
| 连击大师 | 连击20次 | 连击50次 | 连击100次 |

**二、准确率类奖章**

| 奖章 | 铜章 | 银章 | 金章 |
|------|------|------|------|
| 精准射手 | 准确率 >= 90% | >= 95% | >= 99% |
| 零失误 | 1关零错误 | 连续3关零错误 | 连续5关零错误 |
| 完美主义 | 1首古诗全对 | 10首古诗全对 | 全册古诗全对 |

**三、坚持类奖章**

| 奖章 | 铜章 | 银章 | 金章 |
|------|------|------|------|
| 每日之星 | 连续3天打卡 | 连续14天打卡 | 连续30天打卡 |
| 时间旅人 | 累计练习5小时 | 累计20小时 | 累计50小时 |
| 晨型人 | 早上9点前练习3次 | 10次 | 20次 |

**四、教材专属奖章（核心差异化）**

| 奖章 | 获取方式 | 稀有度 |
|------|----------|--------|
| 字母守护者 | 完成26个字母关卡全金星 | 银章 |
| 单词猎人 | 正确输入500个课本单词 | 银章 |
| 诗词达人 | 默写通过20首古诗 | 金章 |
| 课文修复师 | 完成10篇课文修复任务 | 金章 |
| 成语大师 | 成语接龙累计100个 | 金章 |
| 全科通关 | 英语+语文所有章节全金星 | 传说 |

**五、趣味隐藏奖章（惊喜感）**

| 奖章 | 触发条件 | 效果 |
|------|----------|------|
| 夜猫子 | 晚上10点后仍在练习 | 获得星光键盘特效 |
| 速度突破 | 单次WPM超过个人记录50% | 获得闪电称号 |
| 不放弃 | 同一关卡失败5次后通关 | 获得坚毅之心奖章 |
| 一击必杀 | BOSS关一次通关 | 获得天才少年称号 |
| 假期战士 | 暑假期间累计打卡40天 | 获得暑期传奇限定皮肤 |
### 3.4 社交与展示系统

个人英雄主页（可分享给同学/家长）：
- 用户名 + 称号展示
- 等级、总打字量、最高WPM
- 获得奖章统计
- 暑假打卡进度
- 入口：我的奖章墙 / 成长曲线图 / 排行榜

班级排行榜（可选功能）：
- 每周之星（本周练习最多）
- 速度之王（WPM排名）
- 全勤达人（打卡排名）
- 奖章收藏家（奖章最多）
